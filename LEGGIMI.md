# Hullwise — cartella di progetto

1. Estrai questa cartella sul Desktop.
2. Compila i percorsi dei repository di Control Room e Rehaus in `docs/reference/SOURCES.md`.
3. Aprila nel terminale ed esegui `git init`.
4. Avvia Claude Code nella cartella con il prompt:
   "Leggi CLAUDE.md ed esegui tutte le fasi in autonomia, senza fermarti a chiedere."
5. Requisiti sulla macchina: Node.js 20+, pnpm, Docker Desktop in esecuzione.
6. Non mettere in questa cartella né sul computer credenziali di produzione (Shopify, Meta, Google, Supabase di Lorena).

Al ritorno, leggi per primo `docs/EVALUATION.md` (lo scrive Claude Code alla fine) e `docs/PROGRESS.md`.

Contenuto:
- `CLAUDE.md` — brief di sviluppo, letto da Claude Code a ogni sessione
- `docs/reference/command-center-analysis.md` — analisi della piattaforma originale (contesto)
- `docs/reference/SOURCES.md` — percorsi dei repository di Control Room e Rehaus, da compilare
- `docs/PROGRESS.md`, `docs/DECISIONS.md` — avanzamento e decisioni, aggiornati da Claude Code
