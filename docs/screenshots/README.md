# Screenshots

Generated on 2026-10-02 from commit `808ee23` (main after Federico1927/keel#76, the Hullwise rename), demo data only (Northwind Apparel, Harbor Home and the seeded console tenants).

Regenerate with a production build and the demo seed loaded (`pnpm build && pnpm db:reset && pnpm db:migrate && pnpm db:seed`, then `pnpm --filter @hullwise/web start`):

```bash
LOCALES=en,it THEMES=light,dark pnpm --filter @hullwise/web screenshots   # docs/screenshots/<locale>[/dark]/
pnpm --filter @hullwise/landing capture:product && pnpm --filter @hullwise/landing images   # apps/landing/public/screenshots/
pnpm --filter @hullwise/landing build && pnpm --filter @hullwise/landing screenshots         # docs/landing/ and docs/landing/sections/
```

Open Graph cards (`docs/landing/og-{en,it,es}.png`, 1200x630) are the `opengraph-image` files of the landing build; `docs/landing/favicon.png` and `docs/screenshots/app-icon.png` render the SVG marks at 256 px.
